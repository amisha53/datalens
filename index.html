Built for CS 433 — Data Analytics

In CS 433 we spent a lot of time cleaning and visualizing datasets in Python and Excel. I wanted to make that exploration step faster — just drop a file and immediately see the shape of the data before you start writing any code. The AI layer summarizes patterns that would otherwise take several minutes to spot manually.

For data analystsQuickly profile a dataset before writing ETL code — understand distributions, missing values, and column types at a glance.
For business analystsUpload an export from any system (CRM, ERP, ticketing) and instantly communicate findings without needing Python or SQL.
Tech stackVanilla JS · Chart.js · PapaParse · AI inference API. No frameworks, no build step, deploys as a single HTML file.
